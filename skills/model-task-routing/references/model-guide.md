# 角色配置与计量参考

仅在核验原生角色绑定、评估当前工具能执行的较轻模型/档位候选，或解释 token 与成本数据时读取本页。职责选择只按主技能[任务与角色路由](../SKILL.md)；本页不维护角色映射或模型排名。

## 配置发现与实际绑定

- 实际角色配置由当前 Codex 环境注册并加载。查看可见配置时核对 `[agents.<role>].config_file` 指向的 TOML；若当前接口不展示配置来源，核对工具的有效角色绑定，拿不到证据就标为未知。具体发现方式见[Codex 配置接入参考](codex-setup.md)。
- 工具提供原生 `agent_type` 时，先核实该入口实际绑定的模型与档位是否和已注册角色配置相符；同一个角色名不能证明配置一致。核实相符才使用原生入口。若配置不符或无法核实且本次要求特定绑定，只在工具支持显式覆盖时，使用通用派遣传入已核实的模型和档位；工具参数叫 `reasoning_effort` 时传入对应档位值。无显式覆盖能力就说明缺口，不假称已绑定。提示词中的角色名和完整历史继承都不是模型绑定证据。
- 只从当前工具可执行的配置中选择候选。修改配置或 Skill 不会切换已经运行的会话；不能用提示词让当前执行者热切换。
- 旧版按型号、价格或任务类型选择角色的建议已由职责与配置分离的路由方式取代。迁移时保留职责和业务验收约束，删除过时型号、档位和价格映射；不把个人机器型号或历史榜单写入 Skill。
- 只有更新长期角色配置本身时才改其配置源；仅更新职责选择时改主技能。通用角色配置不会扩大权限、费用或项目工作区范围；更严格的项目/专项上限继续有效。

## 较轻配置候选的比较

- 模型或档位更轻只是一项候选，不代表已适用或更省。只在工具能真实执行且任务授权、费用边界允许时比较。
- 对齐同一任务、版本、环境、输入和验收标准；每轮只改变模型或档位之一。材料压缩与交接方式另行比较，避免把多种变化混在一起而无法判断原因。
- 先看验收质量、失败和返工，再对照完整耗时、token、交接与集成成本。输出更短、价格更低或档位更低本身都不能证明总成本下降。
- 没有可靠对照就不报节省比例、不固化模型排名，也不据一次小样本修改默认配置或创建同义角色。Skill 不构成额外费用或权限授权。

## 用量数据的边界

- 每个比较记录任务/turn 的起止、数据截止时点、所用计量窗口和对应配置；说明统计是否覆盖整棵任务树。只比较输入、版本、环境与验收口径一致的结果。
- 标出上下文压缩、会话重置和计量窗口切换。若 last/total 快照的累计规则不明确，不新建这类口径、不把快照相加，也不推断它们之间的包含关系。
- 父级与子级数字的覆盖关系不明时分列并注明未知，不求和。cached input 已包含在 input 里，reasoning 已包含在 output 里，不重复相加。
- 计算整项成本时纳入完整重试、返工、交接、等待和 review；未能采集的部分列为缺口。没有可靠数据就报告“未知”，不拿单价倍数或缓存折扣代替整项测量。

## 游戏场景的业务验收边界

以下约束只在相关游戏任务中使用，不构成另一套角色路由：

| 场景 | 需要保留的判断 |
|---|---|
| 明确的颜色、排序或文案调整 | 按剩余工作判断；保存语义、输入逻辑变化需重新评估。 |
| 路径、依赖或构建入口适配 | 保留引擎版本、资源身份与个人数据；编译时间不由角色档位缩短。 |
| 抛物线、错峰、落点与命中联动 | 发射、表现、判定和声音须保持一致，不能只验证轨迹图。 |
| 武器等级与奖励、解锁联动 | 同查奖励、伤害、表现、说明、存档和统计，不能只改上限数字。 |
| 自动试玩、保存恢复与伤害归属 | 暂停、重开、中途记录、旧投射物快照与异常恢复共同决定正确性。 |
| 按已确认映射批量接入特效 | 按依赖、写入冲突和共享资源拆分；并行数量由就绪包与真实容量决定；保留原资源与事件语义。 |
| 渲染还原、跨平台 Shader 或群体性能根因 | 先取得画面、采样与失败条件；角色升级不能弥补事实缺失。 |

## 证据边界

- 角色配置文件说明预期配置；会话或工具元数据才用于证明实际运行模型与档位。拿不到元数据时标为未知，不从回复风格推断。
- 配置切换、任务交接和局部成功都不能单独证明整体质量。按当前产物、环境和目标检查结果，并分别报告未验证范围。
